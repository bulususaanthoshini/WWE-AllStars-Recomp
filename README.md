## 🔧 Troubleshooting

**The application does not open.**
Make sure you are running it from the folder you created in Step 2 and that your game data is in place. Try starting it again — the first launch is often slower.

**The screen is black or the game will not display.**
This usually points to a graphics problem. Update your graphics card driver through the card manufacturer's website, then try again. Vulkan support is required.

**The game runs slowly or stutters.**
Close other programs, lower the in-game graphics settings, and make sure your laptop is plugged into power rather than running on battery.

**My controller is not detected.**
Unplug the controller, close the game, plug the controller back in, and start the game again. Wired connections are the most reliable.

**Windows shows a security prompt.**
This is normal for software downloaded from the internet. Check that you downloaded it from the official releases page linked above before continuing.
